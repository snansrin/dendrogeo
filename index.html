Yöntem

DBH = Çevre ÷ π
A = π·(DBH/2)² ; Ayatay = A·cos(eğim)
V = A·H·f (f: 0.5)
AGB = 0.0673·(ρ·DBH²·H)^0.976 — Chave et al., 2014
BHB = AGB·0.26 ; C = (AGB+BHB)·0.47 — IPCC 2006
CAGB = AGB·0.47 ; CBHB = BHB·0.47

Odun yoğunlukları (ρ): As ve ark. 2001 · Tolunay 2013 · OGM 299 Nolu Tebliğ 2017.

Veri Doğruluk Politikası

Her kayıt için koordinat, GPS doğruluğu (m), operatör ve zaman damgası saklanır. Fotoğraflar cihaz üstü görüntü analiziyle denetlenir (bitki örtüsü + pozlama kontrolü); hatalı çekimler reddedilir. Kayıtlar admin onayı olmadan dünya verisine işlenmez. DBH ≤ 500 cm, boy ≤ 100 m denetimi uygulanır.

QGIS Fotoğraf Aktarım Rehberi

  1. CSV'yi içe aktar: QGIS → Layer → Add Layer → Add Delimited Text Layer. X = LONGITUDE, Y = LATITUDE, CRS = EPSG:4326.
  2. Tüm veriler katman olur: AGB, BHB, biyokütle, karbon sütunları öznitelik tablosuna işlenir. Identify (i) ile bilgi balonu açılır.
  3. Fotoğraf klasörü: Fotoğrafları tek klasöre koy (örn. C:/dendro_foto/). Dosya adları PHOTO_FILE ile aynı olmalı.
  4. Fotoğraf balonu: Katman Özellikleri → Display → HTML Map Tip:
    <img src="file:///C:/dendro_foto/[% "PHOTO_FILE" %]" width="220">
  5. Etkinleştir: View → Show Map Tips.
  6. Etiket: Labels → POINT_ID.
