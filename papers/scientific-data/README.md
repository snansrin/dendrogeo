# Scientific Data Data Descriptor draft

The manuscript is structured around the journal's Data Descriptor sections. It is intentionally marked as a working draft because a submission requires a defined, rights-cleared dataset deposited in a suitable repository, stable accession/DOI, exact file inventory, validated methods, and author-confirmed affiliations and declarations.

Do not submit the draft with bracketed fields or use private/unpublished user records. The journal requires reviewer access to the dataset and public repository availability by later review/publication stages.
