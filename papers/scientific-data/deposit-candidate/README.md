# Göksu Park tree data deposit candidate

This local author-review package contains a fixed snapshot of 36 public tree records from 28 September to 1 October 2026. Fieldwork is ongoing.

tree-observations.csv contains field observations and location metadata. derived-estimates.csv contains the separately identified stored model outputs. Join on point_id. Blank horizontal_accuracy_m values are unknown, not zero. See data-dictionary.csv for source mappings.

The source report is DGR-2026-0026, DOI 10.5281/zenodo.23404310. It remains unchanged under its original licence. The new, narrowly scoped tables have CC BY 4.0 rights-holder authorization; see LICENSE.txt. OSM-derived geometry, imagery and photographs are excluded.

This is not a registered dataset deposit or journal submission. No dataset DOI exists yet. Confirm authorship, affiliations, methods and declarations before upload.
