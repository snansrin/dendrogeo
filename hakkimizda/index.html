DendroGeo Hakkında

DendroGeo, saha ağaç envanteri, karbon hesaplama, park analizi ve web GIS haritalamasını aynı platformda birleştiren açık kaynaklı bir projedir.

DendroGeo uygulamasını aç

Projenin amacı

DendroGeo'nun odağı, sahada ölçülen ağaç verisini konumsal bağlamıyla koruyarak biyokütle ve karbon hesaplarına, haritalamaya ve park ölçeğinde analizlere bağlamaktır.

Açık kaynak yapı

Uygulama statik web arayüzü, PWA bileşenleri, istemci JavaScript servisleri ve Supabase tabanlı veri katmanından oluşur. Kod, yöntem dokümanları ve testler GitHub deposunda tutulur.

Proje kaynakları

GitHub deposu üzerinden kaynak koda, testlere ve yöntem belgelerine ulaşılabilir.
